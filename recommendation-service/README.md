# 🎬 CineBrain Recommendation Service

The **Recommendation Service** is the recommendation layer of CineBrain, a movie recommendation and Retrieval-Augmented Generation (RAG) platform.

It provides two recommendation approaches:

- **Collaborative filtering** using MovieLens ratings and an SVD model.
- **Content-based filtering** using movie embeddings stored in Qdrant.

The service runs as a FastAPI application and connects to the Qdrant service used by the Embedding Service.

---

## Responsibilities

| File | Responsibility |
| --- | --- |
| `main.py` | Creates the FastAPI application and registers recommendation routes |
| `collaborative_recommender.py` | Loads, trains, predicts, and ranks collaborative recommendations |
| `content_recommender.py` | Retrieves Qdrant embeddings and finds similar movies |
| `qdrant_client.py` | Connects to the local Qdrant server |
| `train.py` | Loads MovieLens ratings and trains the collaborative model |
| `routes/recommendation.py` | Exposes collaborative and content-based recommendation endpoints |
| `requirements.txt` | Python dependencies |

---

# 1. Create the Python Environment

From the CineBrain project directory:

```bash
cd CineBrain/recommendation-service
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

```bash
source .venv/bin/activate
```

---

# 2. Install Dependencies

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 3. Prepare the Training Data

The collaborative recommender uses the MovieLens ratings data in `data/ratings.csv`.

The training script reads:

```text
data/ratings.csv
```

The ratings dataset must contain the `userId`, `movieId`, and `rating` columns.

---

# 4. Train the Collaborative Model

From the recommendation-service directory, run:

```bash
python3 -m app.train
```

The training process:

1. Reads `data/ratings.csv`.
2. Builds a Surprise dataset using the user, movie, and rating columns.
3. Trains an SVD model with a rating scale from `0.5` to `5`.
4. Saves the model and movie metadata to `models/recommender.pkl`.

The model can be loaded automatically when the service starts if the serialized model already exists.

---

# 5. Configure Qdrant

The content-based recommender connects to Qdrant at:

```text
localhost:6333
```

Start Qdrant locally if it is not already running:

```bash
docker run --rm -p 6333:6333 -p 6334:6334 qdrant/qdrant
```

The Qdrant collection must contain movie embeddings generated by the Embedding Service. The content-based endpoint returns recommendations only when the requested movie ID exists in that collection.

---

# 6. Run the Recommendation Service

From the recommendation-service directory:

```bash
uvicorn app.main:app --reload --port 8002
```

The service should be available at:

```text
http://127.0.0.1:8002
```

---

# 7. API Endpoints

## Service health

```bash
curl http://127.0.0.1:8002/
```

The response is:

```json
{
  "message": "Recommendation service running"
}
```

## Collaborative recommendations for a user

```bash
curl "http://127.0.0.1:8002/recommendations/user/1?top_k=10"
```

The response contains the user's ID and the highest-scoring unrated movies produced by the SVD model:

```json
{
  "user_id": 1,
  "recommendations": [
    {
      "movie_id": 2,
      "score": 4.5
    }
  ]
}
```

The `top_k` query parameter controls the maximum number of recommendations and defaults to `10`.

## Content-based recommendations for a movie

```bash
curl "http://127.0.0.1:8002/recommendations/movie/1?top_k=10"
```

The endpoint retrieves the movie embedding from Qdrant, searches for similar vectors, and returns their movie IDs, titles, and similarity scores.

---

# 8. Recommendation Flow

```text
MovieLens ratings
    │
    ▼
CollaborativeRecommender
    ├── Trains SVD model
    ├── Saves models/recommender.pkl
    └── Returns ranked user recommendations

Movie embedding in Qdrant
    │
    ▼
ContentBasedRecommender
    ├── Retrieves the selected movie vector
    ├── Searches nearby movie vectors
    └── Returns similar movies
```
